WebRTC network test

Throwaway test for a game's peer-to-peer multiplayer. It sends random test messages for 30 seconds and shows timing and loss. No game data, no accounts. The other player's browser and the PeerJS public server (and its STUN/TURN servers) can see your IP address.

One person presses Host. The other opens the same page on a different network and enters the code (or opens the link).
